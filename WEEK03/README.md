# REFLEKSI #
Hari ini saya belajar tentang: Pembangunan permainan web HTML menggunakan bantuan ChatGPT, serta pengaplikasian HTML, CSS, dan JavaScript dalam menghasilkan permainan yang interaktif.

Perkara yang paling saya fahami: Cara mereka bentuk antaramuka (UI) permainan, membina kawalan paddle berasaskan pergerakan tetikus, serta menerapkan animasi dan kesan visual neon yang menarik.

Perkara yang masih kurang saya fahami: Logik JavaScript yang lebih mendalam, terutamanya struktur sistem skor lanjutan, penjanaan kesan partikel (particle effects), dan teknik pengoptimuman prestasi permainan.

Langkah peningkatan pemahaman: Saya akan terus bereksperimen dengan mengedit kod sedia ada, merujuk dokumentasi rasmi JavaScript, dan membina lebih banyak projek permainan HTML secara praktikal.
